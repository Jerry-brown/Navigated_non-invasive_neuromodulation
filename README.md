# Navigated non-invasive neuromodulation

This repository accompanies the manuscript “A hierarchical face-scalp-cortex mapping for non-invasive neuromodulation targeting without magnetic resonance images guidance.” The work introduces an MRI-free targeting framework that maps facial surface topology to the scalp, then estimates cortical targets using a scalp angle coordinate system. The repository contains the generative modeling code, SAC-related data, the manuscript, and its supplementary figures.

## Files

- `GM/` — generative modeling code for the face-to-scalp mapping component.
- `SAC/` — data associated with the scalp angle coordinate system.
- [`article.pdf`](article.pdf) — manuscript.
- [`SI_figure.pdf`](SI_figure.pdf) — supplementary figures.
